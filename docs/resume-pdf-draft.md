## 3p · 포트폴리오 1 — 오늘어디
**사실은 API가, 규칙은 코드가, 취향 판단만 LLM이 — 데이트 코스 추천 앱**
개인 · 2026.09 ~ · 기획·풀스택 · GitHub 링크

- **문제** — 코스 추천을 LLM에 통째로 맡기면 없는 가게, 지어낸 버스 시간, 예산을 넘는 코스가 섞여 나왔습니다. 웹 조사까지 한 호출에 넣으면 20초가 넘었고 근거가 어느 글에서 왔는지 남지 않았습니다.
- **내 판단** — LLM의 일을 "비정형 글 구조화"와 "후보 안에서 고르기" 둘로 한정했습니다. 좌표·경로·시간은 카카오 API, 예산·주차·영업 시간 규칙은 코드가 맡고, 모르는 값은 0이 아니라 "모름"으로 다룹니다.
- **구현**
  - 추천 1회의 LLM 호출은 추출 3번 + 조합 1번뿐, 나머지는 결정적인 코드
  - Tavily로 블로그·인스타·웹을 출처별로 검색하고 본문에 [1] 번호를 붙여, LLM은 번호로만 출처를 돌려주게 해 링크를 지어낼 수 없게 함
  - LLM이 낸 코스를 코드가 재검사 — 후보에 없는 장소 제거, 알려진 가격 합 × 2가 예산을 넘거나 시간표가 안 맞는 코스 탈락
  - 결측 처리 — 가격 모름은 합계에서 빼고 "+α", 주차 정보 없음 표시, 경로 API 실패 시 직선거리 × 1.3 어림값과 "어림" 표기
  - 네이버 검색 API는 개정 약관이 AI 입력·저장을 금지해 쓰지 않음 (약관 검토)
- **결과** — 출처별 병렬 추출로 **20초+ → 3~5초**(무료 등급 모델) · 지역 캐시로 첫 조사 13~20초 → 적중 시 4~5초 · API 없이 도는 판정 로직 테스트 **56개**
- **기술** — Expo(React Native), TypeScript, NestJS, PostgreSQL, Prisma, zod, Gemini, Tavily, Kakao Local·Mobility API, Render
- **구조도** — 입력 → 좌표 변환 → [지도 검색 ∥ 웹 조사 → 출처별 추출 ×3] → 이름 매칭 → 코드 필터 → **LLM 조합** → 코드 검증 → 경로·시간표 (LLM 단계만 포인트 색)

## 7p · 포트폴리오 5 — 결제 중개 · 멀티 PG
**하나의 결제창에 여러 PG를 — 웹뷰 제약까지**
(주)셀메이트 · 2025.03 ~ 2026.03 · MR 178건

- **구현**

  - 웹뷰 우회 — localStorage 브리지 + 전용 페이지로 외부 브라우저에서 결제
  - 569줄 스크립트를 PayPal · Apple Pay · Google Pay · 카드 모듈로 분리

  - 로컬 재현이 어려운 결제를 스테이지·QA 환경 반복 배포로 검증
- **결과** — PG **6개**(PayPal·INICIS·Eximbay·LINE Pay·Toss 등) · 실패 화면 **5개 언어** · 569줄 → 결제수단별 4개 모듈 · MR **178건**
- **기술** — FastAPI, Jinja2, JavaScript(ES Modules), PayPal JS SDK, Sentry
- **구조도** — 결제창 → merchant-id 기반 PG 매칭 → [PayPal · INICIS · Eximbay · LINE Pay · Toss …] → 성공 / 취소 / 실패 → 5개 언어 화면

## 8p · 포트폴리오 6 — Orbit
**프론트엔드 개발자가 백엔드·DB·배포까지 — 학습 동기부여 웹앱**
개인 · 2026.07 · 풀스택 · Live · GitHub 링크

- **문제** — PC에서는 정상인데 iOS Safari에서만 로그인 직후 세션이 사라졌습니다. 진행도·스트릭을 별도로 저장하면 기록 삭제 시 실제와 어긋날 수 있었습니다.
- **내 판단** — 프론트(Vercel)와 백엔드(Railway)가 다른 사이트라 세션 쿠키가 제3자 쿠키로 차단된 것. 쿠키 속성을 푸는(SameSite=None) 대신 브라우저 입장에서 같은 출처가 되게 한다. 파생값은 저장하지 않고 계산한다.
- **구현**
  - Next.js rewrites로 `/api` 프록시 → same-origin 요청, 쿠키는 SameSite=Lax로 복귀
  - CORS · OAuth 콜백 · 쿠키 속성을 환경변수로 분리해 배포 환경마다 교체
  - FastAPI를 api → services → models로 계층화, 진행도·스트릭은 조회 시 기록에서 계산(UTC → KST 자정 경계)
  - Vercel · Railway · Neon · Cloudinary 분리 배포, GitHub Actions CI(ruff/pytest, tsc/eslint/vitest)
- **결과** — pytest **65개** · Vitest **102개** · Playwright E2E **29개** · iOS Safari 세션 유실 해결 · 기록-진행도 불일치 원천 차단
- **기술** — Next.js, React, TypeScript, React Three Fiber, FastAPI, PostgreSQL, Google OAuth, GitHub Actions, Vercel, Railway, Neon
- **구조도** — 브라우저 → Vercel(Next.js · `/api` rewrite, 같은 출처) → Railway(FastAPI) → Neon(PostgreSQL)
