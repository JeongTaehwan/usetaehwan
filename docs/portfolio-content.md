# usetaehwan.page — 사이트 콘텐츠

첨부한 레이아웃 이미지(Portfolio Site v2)를 **참고**해서, 아래 콘텐츠로 실제 페이지를 만들어줘.

## 작업 지침
- 픽셀 단위 복제가 아니라, 레이아웃 구조(상단 네비 + 넓은 캔버스, 섹션 구성, 여백감)를 참고할 것
- 반드시 `design-system/components`의 컴포넌트(Button, Input, Card, Badge, Typography, Container)를 사용
- 색·간격 하드코딩 금지. 토큰만 참조 (CLAUDE.md 규칙 준수)
- 라이트/다크 토글 포함
- 반응형 (모바일 대응)
- 아직 자료가 없는 Experience 항목(리팩토링/결제중개/리액트웹앱/스캔페이)과 Projects는 자연스러운 placeholder로 두되, 구조는 잡아둘 것

## 모션 / 인터랙션 지침
전체 톤은 "차분한 문서"다. 화려하게 도배하지 말고, 절제된 모션을 의도적으로 배치할 것.
- **라이브러리:** Framer Motion 사용 (순수 React 라이브러리, next/* 아님 — 규칙 준수)
- **스크롤 진입:** 각 섹션이 나타날 때 은은한 fade + slide-up (짧고 부드럽게, 과하지 않게)
- **Hero:** 텍스트 순차 등장 (단어/줄 단위 fade-in 정도. 통통 튀는 과한 모션 금지)
- **다크모드 전환:** 색이 즉시 바뀌지 말고 부드러운 컬러 트랜지션
- **컴포넌트 호버:** 이미 컴포넌트에 있는 transition 활용, 미세하게
- **Design System 섹션 — 인터랙티브 데모 (핵심):** 방문자가 토큰(예: 브랜드 색)을 조작하면 그 자리에서 컴포넌트들이 실시간으로 바뀌는 데모를 넣을 것. "디자인 시스템이 토큰 기반으로 동작한다"를 직접 체험시키는 것이 목적. 이 섹션이 사이트의 기술적 하이라이트.
- 접근성: `prefers-reduced-motion` 존중 (모션 끄기 설정 시 애니메이션 최소화)

### StoreX Admin — 멀티테넌트 쇼핑몰 어드민 프론트엔드

기존 프로젝트를 인계받아 20개 이상의 관리 페이지(상품·브랜드·쿠폰·포인트·주문·리뷰 등)를 단독으로 유지보수 및 신규 개발. 이후 후임 합류에 따라 온보딩과 코드 리뷰를 담당하며 협업 체계로 전환. 테넌트별 마켓·다국어 구조를 대응해, 현재 2개 고객사·5개 마켓(일본·미국·한국·대만)·72개 브랜드가 운영되는 플랫폼을 담당.

## § 04 · Design System

**읽고 있는 이 문서, 그 문서가 만든 화면입니다**

`useTaehwan()/ui` — 저채도 웜 뉴트럴 토큰과 6개의 React 프리미티브로 구성된 작은 디자인 시스템입니다. 색 하나를 바꾸면 사이트 전체가 따라 바뀝니다. 이 페이지가 그 증거입니다.

아래에 실물 전시:
- 토큰 스와치 (컬러 팔레트, 라이트/다크)
- 컴포넌트 데모 (Button variant/size, Badge, Input, Card 등)
- "6 primitives · token-only · light + dark" 캡션
